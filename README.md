# 둥지 (Nest) 🐣

> **혼자 살아도, 든든하게** — 자취생·청년 1인 가구를 위한 AI 주거 생활 도우미.

집에서 생긴 문제(곰팡이·누수·보일러·변기막힘 등)를 **사진/텍스트**로 물으면, AI가
**① 셀프 응급처치 → ② 집주인 vs 세입자 책임 판단 → ③ 집주인에게 보낼 연락 문구**까지
3단으로 답해줍니다. 정보가 부족한 청년 세입자가 자기 권리를 알고 행동하도록 돕는 것이 목표입니다.

2026 K-AI 콘텐츠 공모전(주최: KT 희망나눔재단) Track B 솔루션 부문 출품작.

## 기능

- **🏠 집 수리 — 살림 응급실 (메인)**: 사진/텍스트 → 응급처치 · 책임 판단(민법 제623조·판례) · 집주인 문구(정중/단호 토글 + 복사). 원인 모호 시 1회 되묻기, 긴급도 신호등, 맥락 인지형 수리 업체 연결.
- **📄 계약서 독소조항 체커 (베타)**: 임대차계약서(특약 포함)를 붙여넣으면 세입자에게 불리한 조항 탐지 — 위험도·근거 법조(주택임대차보호법/민법/약관규제법)·대응 문구 + 원문 형광펜. 룰북(`lib/legal/`) 1차 기준.
- **📋 이사·행정 길잡이**: 전입신고·확정일자·보증보험·공과금 명의변경 맞춤 체크리스트
- **💡 공과금 점검**: 요금 입력 → 1인 가구 평균 대비 진단 + 절약 팁 (출처 표기)
- **📊 전월세 시세 참고 (베타)**: 주소 검색(동 단위) → 국토교통부 실거래 신고가 요약·최근 계약 내역 + 내 월세 비교 미터. 키 미설정 시 "예시 데이터"를 명시하고 폴백.
- **🛒 혼밥 장보기 코치**: ① 예산·식성 → 일주일 식단 + 마트 동선별 장보기 리스트(KAMIS 오늘 시세·제철·보관 팁·예산 초과 대체재 추천), ② 남은 재료 또는 냉장고 사진 → 소진 우선 메뉴(Pexels 참고 이미지·식약처 공공 레시피)
- **🎬 인터랙티브 쇼케이스 (`/showcase`)**: 심사·발표용 90초 데모. 시나리오 4종 × 4단계 스테퍼, 데이터 접지 카드 10종, 발표자 모드(`?present=1`, 방향키 이동·Esc 종료)
- **💳 주거비 자동분석 (베타)**: 금융결제원 **오픈뱅킹 테스트베드(모의계좌)** 기반 PoC.
  거래내역을 월세·관리비·전기·가스·수도·통신비로 자동 분류·집계. `/money` 라우트로 **격리**되고,
  화면에 "테스트베드(모의데이터)"를 명확히 표기. 환경변수 미설정 시 "베타 준비중"으로 안전 표시.

설계는 "**엔진 1개 + 테마 입구 4개**" — 집수리/행정/공과금 입력 UI·API 호출·결과 렌더는 공통
컴포넌트로 재사용하고, 주제별로 시스템 프롬프트만 교체합니다. (주거비 분석 베타는 메인 앱의
'개인정보 미수집' 가치와 섞이지 않도록 별도 페이지로 분리.)

## 기술 스택

- **Next.js 14 (App Router)** + TypeScript + Tailwind CSS
- **Anthropic Claude API** (`claude-opus-4-8`, 멀티모달/비전) — 서버 라우트에서만 호출
- 배포: **Vercel**

## 로컬 실행

```bash
# 1) 의존성 설치
npm install

# 2) 환경 변수 설정
cp .env.example .env.local
# .env.local 을 열어 ANTHROPIC_API_KEY 에 실제 키 입력

# 3) 개발 서버
npm run dev   # http://localhost:3000
```

## 환경 변수

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | ✅ | Claude API 키 (서버에서만 사용, 레포에 커밋 금지) |
| `ANTHROPIC_MODEL` | – | 사용할 모델 ID (기본 `claude-opus-4-8`) |
| `ANTHROPIC_MODEL_TEXT` | – | 텍스트 전용 요청 라우팅용 모델 (비용·속도 최적화) |
| `LAW_API_OC` | – | 법제처 법령 API — 계약서 근거를 현행 원문으로 승격 |
| `DATA_GO_KR_SERVICE_KEY` | – | 공공데이터포털 공용 키 — 실거래가·기상청·공휴일·건축물대장 |
| `KAKAO_REST_API_KEY` | – | 수리 결과의 주변 업체 미리보기 (없으면 지도 링크 폴백) |
| `KAMIS_CERT_KEY`/`_ID` | – | 장보기 오늘 시세 (없으면 내장 참고가 폴백) |
| `PEXELS_API_KEY` | – | 음식 참고 이미지 (없으면 텍스트 카드 폴백) |
| `FOODSAFETY_API_KEY` | – | 식약처 공공 레시피 (없으면 섹션 생략) |
| `OPENBANKING_*` | – | 주거비 분석 베타용(오픈뱅킹 테스트베드). 미설정 시 `/money`는 "베타 준비중" 표시. `.env.example` 참고 |

모든 선택 키는 **없어도 앱이 깨지지 않으며**, 화면에 폴백 상태(참고가·예시 데이터 등)를
정직하게 표시합니다. 심사 시연 순서는 `docs/JUDGE_DEMO_SCRIPT.md` 참고.

## 배포 (Vercel)

1. 이 레포를 Vercel에 임포트
2. Environment Variables 에 `ANTHROPIC_API_KEY` 추가
3. 빌드 → 배포 URL 확인 (`npm run build` 가 통과하는지 사전 확인 권장)

## 개인정보 · 보안 · 라이선스

- 로그인·회원가입 없음. **개인정보를 수집·저장하지 않습니다.** 업로드한 사진·텍스트는
  API 처리 후 서버에 영구 저장하지 않습니다.
- API 키는 **서버 라우트(`app/api/assist`)에서만** 사용하며 클라이언트 번들/레포에 노출되지 않습니다.
- 책임 판단·문구는 **참고용이며 법적 자문이 아닙니다.** 분쟁 시 주택임대차분쟁조정위원회 또는
  변호사 상담을 권장합니다 (결과·푸터에 명시).
- 수리 업체 연결은 사설 업체를 등록·보증하지 않고 **지도 앱 검색 + 공식 연락처**로만 연결하며,
  위치·연락처를 수집·저장하지 않습니다.
- **주거비 분석 베타**는 오픈뱅킹 **테스트베드(모의계좌)** 로만 동작합니다. `client_secret`·토큰은
  서버 라우트에서만 사용하고(클라이언트 노출 금지), 토큰은 httpOnly 쿠키에 데모 세션 동안만
  임시 보관하며 DB에 영구 저장하지 않습니다. 실계좌·실금융정보는 다루지 않습니다.
- **계약서 체커**는 붙여넣은 계약서를 서버에 저장하지 않습니다(처리 후 폐기, 로그 미기록). 법령 근거는
  국가법령정보센터 출처를 표기하며, 결과는 참고용·법적 자문이 아님을 명시합니다.
