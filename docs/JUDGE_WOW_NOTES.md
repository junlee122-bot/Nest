# 심사 데모 wow 포인트 메모 (v11 기준)

발표에서 "오" 소리가 나는 장면과, 어디를 누르면 나오는지 정리한 메모입니다.
발표 순서·멘트·Q&A는 `docs/JUDGE_DEMO_SCRIPT.md` 참고.

## 확실한 wow 장면 10

1. **/showcase 단계별 목업** — 스테퍼(입력→AI 판단→데이터 보강→바로 행동)를 누르면
   폰 목업 안에서 스켈레톤이 결과 카드로 바뀜. 시나리오 4종 전환.
2. **발표자 모드** — `/showcase?present=1`. 발표 멘트·진행바·방향키/Space/Esc.
3. **집수리 예시 결과** — 긴급도 신호등 → 오늘 할 일 → 집주인 문구(정중/단호 토글 +
   직접 수정 가능한 textarea) → 하단 고정 복사/문자 바.
4. **증거 기록 패키지** — 체크리스트(결과별 저장) + 기록용 메모 양식 복사.
5. **계약서 위험 형광펜** — 원문에서 위험도별 색(레드/앰버/스카이)으로 하이라이트 + 범례,
   원문(레드)→수정 요청(그린) diff 카드 + 복사.
6. **월세 비교 미터** — 내 월세를 입력하면 최근 거래 중앙값 대비 위치가 점으로 찍힘
   (참고 비교 명시) + "계약 전에 이렇게 물어보세요" 복사 문구.
7. **냉장고 사진 스캔** — 사진 올리면 스캔 라인이 지나가고 재료 칩이 하나씩 등장,
   틀린 칩은 X로 제거(입력창 동기화).
8. **장보기 데이터 접지** — 가격 출처 배지(오늘 시세/참고가/AI 추정), 제철 칩,
   먼저 먹을 순서, 예산 초과 시 대체재 카드(참고가 기준 절약액), 마트용 리스트 복사.
9. **Pexels 음식 사진 + 크레딧** — AI 메뉴명으로 참고 이미지 검색, "참고 이미지" 표기.
10. **데이터 접지 그리드(/showcase)** — 연동 10종 각각의 보강 내용/무키 폴백/표시 방식.

## 폴백 안정성 (심사 중 키가 없어도)

- 모든 기능에 "예시로 둘러보기" — AI 키 없이 전체 흐름 시연 가능
- KAMIS→참고가, Pexels→텍스트, RTMS→예시 배지, 식약처→섹션 생략, Kakao→지도 링크
- 상세 표: `docs/API_FALLBACKS.md`

## 신뢰 포인트 (질문 들어오면)

- 신뢰 배지 5종(쇼케이스·전체 탭 하단): 사진 저장 안 함 / 계약서 원문 저장 안 함 /
  API 키 서버 전용 / 출처 표시 / 법적 자문 아님
- AI 스키마와 서버 부착 데이터 분리, validator+재시도, 버킷 레이트리밋, 보안 헤더
- 정책 상세: `docs/SECURITY_PRIVACY.md`
