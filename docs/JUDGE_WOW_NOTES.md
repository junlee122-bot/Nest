# 심사 데모 wow 포인트 메모

## 이번 버전에 추가한 것

### 1) 음식 이미지 API 연동
- `PEXELS_API_KEY`를 설정하면 `/api/grocery`가 AI 식단/추천 메뉴 이름으로 Pexels 사진을 검색해 결과 JSON에 `photo`를 붙입니다.
- 키가 없거나 실패하면 기존 텍스트 카드로 조용히 폴백합니다.
- UI는 사진 하단에 Pexels/작가 크레딧을 노출합니다.

```env
PEXELS_API_KEY=...
```

주요 파일:
- `lib/integrations/foodImages.ts`
- `app/api/grocery/route.ts`
- `components/GroceryCoach.tsx`
- `lib/types.ts`

### 2) 데모에서 보여줄 순서
1. `/grocery` 진입
2. 예산: `35000원`
3. 기간: `7일`
4. 식성: `간단한 것만`, 난이도: `아주 간단`
5. 결과에서 보여줄 포인트:
   - 요일별 식단 카드에 음식 사진이 자동 노출
   - 장보기 리스트에는 오늘 시세/참고가/제철/보관 팁
   - 가격은 KAMIS가 있으면 오늘 시세, 없으면 내장 참고가로 폴백
6. 탭을 `남은 재료 처리`로 전환
7. `두부, 계란, 김치, 대파` 입력
8. 결과에서 보여줄 포인트:
   - 상하기 쉬운 재료 먼저 쓰는 순서
   - AI 추천 레시피 사진
   - FOODSAFETY_API_KEY가 있으면 식약처 공공 레시피 사진/열량/조리 단계

## 다음 wow 후보

### A. 냉장고 사진 → 재료 자동 추출
수리 사진 업로드 경험을 장보기에도 확장합니다.
- 사용자가 냉장고 사진 업로드
- Claude vision으로 재료명 추출
- 기존 `남은 재료 처리` 플로우에 자동 입력
- 심사위원에게 가장 직관적인 장면: “사진 한 장으로 오늘 뭐 먹을지 추천”

### B. 지도/근처 마트/수리업체 연결
현재 Kakao Local 연동을 수리업체에 쓰고 있다면 장보기에도 확장할 수 있습니다.
- 장보기 리스트 기반 “근처 마트/전통시장” 탐색
- 수리 결과에서는 “근처 누수/보일러 업체” 미리보기

### C. 월세/관리비 anomaly 카드
머니/오픈뱅킹 베타와 연결해 “월세+관리비 이상치”를 한 카드로 보여줍니다.
- 이번 달 관리비가 평소보다 38% 높아요
- 전기/가스/수도 중 원인 추정
- 임대차/공과금 상담 플로우로 연결
