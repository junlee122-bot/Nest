# 둥지 인터랙티브 쇼케이스

심사위원이 90초 안에 제품 가치를 이해하도록 만든 스크롤형 웹사이트입니다.

## 경로

- `/showcase`
- 홈과 전체 탭에 `90초 인터랙티브 쇼케이스` 카드가 노출됩니다.

## 데모 순서

1. `/showcase` 진입
2. `90초 데모 시작` 클릭
3. 누수 사진 진단 → 계약서 위험 조항 → 혼밥 장보기 시나리오가 자동 순환되는 것을 보여줌
4. `데이터가 붙으면 데모가 달라집니다` 섹션에서 KAMIS, 식약처, Pexels, RTMS 등 데이터 신호를 눌러 보여줌
5. 마지막 섹션에서 `수리 진단 체험` 또는 `장보기 코치 보기`로 실제 앱 진입

## 심사위원에게 강조할 포인트

- 둥지는 단순 챗봇이 아니라 문제를 `입력 → 판단 → 데이터 보강 → 행동 카드`로 바꿉니다.
- 주거 문제에서는 사진/문장 입력을 응급처치, 책임 가능성, 집주인 메시지로 연결합니다.
- 장보기에서는 AI 식단에 음식 이미지 API, KAMIS 시세, 제철/보관 데이터를 붙여 시각적 완성도를 높입니다.
- 쇼케이스 페이지는 실제 기능을 설명하기 전에 제품의 방향성과 데이터 접지 구조를 보여주는 발표용 허브입니다.

## 연동 API

- `PEXELS_API_KEY`: 메뉴명 기반 음식 사진 검색
- `KAMIS_CERT_KEY`, `KAMIS_CERT_ID`: 농축수산물 가격 참고
- `FOODSAFETY_API_KEY`: 식약처 공공 레시피 이미지/조리 단계
