## 타임아웃·캐시 (lib/integrations/core.ts)

- 모든 외부 호출: `AbortSignal.timeout` 기반 타임아웃, 실패 시 null 반환 → UI 폴백
- 메모리 TTL 캐시(withCache) + 실패 5분 캐시 (같은 실패 반복 호출 방지)
- KAMIS는 실측 20~90초 지연이 있어 2.5초 레이스 후 폴백,
  백그라운드 완료분이 캐시에 들어가 다음 요청부터 "오늘 시세"가 붙음
- Pexels: 메뉴명 기준 24시간 캐시, 요청당 최대 4개 메뉴만 이미지 검색
