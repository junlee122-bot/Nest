# 에어컨 전기요금 계산기

`/utility` 기본 탭의 에어컨 전기요금 계산기 설계 문서.

## 목적

에어컨 종류·냉방 평수·하루 사용시간 세 가지만으로, 한 달 동안 가정 전체 전기요금에
**더해질 것으로 예상되는 추가요금**을 즉시 보여준다. 데모 목업이 아니라 모든 입력과
계산이 브라우저 안에서 실제로 동작한다.

## 왜 AI(LLM)를 호출하지 않는가

- 같은 입력에는 항상 같은 결과가 나와야 한다 (결정론).
- 단위 테스트로 한전 요금표와의 일치를 검증할 수 있어야 한다.
- API 비용·네트워크 상태와 무관하게 즉시 계산돼야 한다.
- 숫자를 LLM이 임의로 생성하는 위험을 차단한다.

→ `lib/electricity/`의 순수 TypeScript 함수로만 계산한다. 계산 중 fetch 0회.
   기존 `/api/assist` AI는 "고지서·공과금 점검" 탭에서만 쓴다.

## 사용자 입력

기본: 에어컨 종류(벽걸이/스탠드/창문형/이동식/멀티) · 냉방 평수(1~60, 0.5단위) ·
하루 사용시간(0.5~24) · 월 사용일수(1~31, 기본 30)

고급(선택): 제품 라벨 냉방 소비전력(100~5,000W) · 인버터/정속/모름 ·
평소 월 사용량(0~1,500kWh) · 저압/고압 · 계산 월 · 냉방 환경

## 추가요금 계산 방식 (핵심)

"에어컨 kWh × 평균 단가"가 아니라 **가정 전체 누진요금의 전/후 차이**:

```
additionalCost = bill(baseline + airconKwh).total - bill(baseline).total
```

누진구간·기본요금 구간 변화, 기후환경요금(9원/kWh), 연료비조정요금(+5원/kWh),
부가세(10%, 원단위 4사5입), 전력산업기반기금(2.7%, 10원 절사), 최종 10원 절사까지 반영.

평소 사용량 미입력 시 낮음 150 / 중앙 200 / 높음 250kWh 시나리오로 범위를 계산하고
그 사실을 화면에 표시한다.

## 에어컨 전력량 추정 모델 (앱 휴리스틱 — 공식 스펙 아님)

1. 필요 냉방출력 = 평수 × 0.4kW
2. 입력전력 = 냉방출력 ÷ 유형별 추정 효율, 유형별 현실 범위로 clamp
3. 라벨 소비전력 입력 시 그 값이 추정을 대체 (범위 계수도 ±15% → ±5%로 축소)
4. 하루 사용량 = 입력전력 × (첫 1시간 부하율 + 이후 시간 × 정상 부하율) × 환경 계수 × 멀티 계수

### 유형별 프로필

| 유형 | 효율비 | 입력전력 범위 | 권장 면적 |
| --- | --- | --- | --- |
| 벽걸이 | 3.5 | 0.42~1.35kW | 4~10평 |
| 스탠드 | 3.4 | 1.10~3.30kW | 12~30평 |
| 창문형 | 2.9 | 0.50~1.30kW | 4~9평 |
| 이동식 | 2.5 | 0.75~1.70kW | 4~8평 |
| 멀티 | 3.3 | 1.40~3.80kW | 15~35평 |

멀티 "둘 다 사용" 시 ×1.25 (실외기 제어 모델이 아닌 범위 추정용).

### 부하율 (첫 1시간 / 이후)

| 방식 | 낮음 | 중앙 | 높음 |
| --- | --- | --- | --- |
| 인버터 | 0.75/0.32 | 0.90/0.48 | 1.00/0.68 |
| 정속 | 0.85/0.55 | 1.00/0.72 | 1.05/0.90 |
| 모름 | 0.80/0.42 | 0.95/0.60 | 1.05/0.82 |

환경 계수: 유리 0.80/0.90/1.00 · 보통 0.90/1.00/1.15 · 불리 1.00/1.15/1.35

불변식: low ≤ central ≤ high, 0 이상, NaN/Infinity 없음 (테스트로 보증).

  (1·2·7·8·12월, 저압 736.2 / 고압 601.3원)

## 계산에서 제외

TV 수신료, 복지·대가족·자동이체 등 할인, 공동주택 공용 전기·관리사무소 배분,
1주택 수가구, 태양광 상계, 제주 계시별 등 개별 계약. (화면 하단에 고지)

## 표시 규칙

엔진은 10원 단위까지 정확히 계산하되, 추정 금액은 1,000원 단위 반올림
("약 24,000원 / 범위 17,000~33,000원"), kWh는 소수 첫째 자리. 과신 방지 목적.

## 정확도를 높이는 방법 (화면에도 안내)

1. 라벨의 냉방 소비전력 입력 2. 고지서의 월 사용량 입력 3. 저압/고압 확인
